# Editorial Luxury (Lifestyle / Real Estate / Agency)

Warm creams (FDFBF7), muted sage, or deep espresso tones. High-contrast Variable Serif fonts for massive head…

> 来源：TasteSkill

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #FDFBF7 |
| surface | #efedea |
| text | #18181b |
| muted | #7f7e7e |
| accent | #6366F1 |
| accent2 | #494BA6 |

## 关键参数

- 质感类：editorial
- 字体：serif
- 圆角：14px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Editorial Luxury (Lifestyle / Real Estate / Agency) — editorial */
.aek-stage {
  --p-bg: #FDFBF7;
  --p-surface: #efedea;
  --p-text: #18181b;
  --p-muted: #7f7e7e;
  --p-accent: #6366F1;
  --p-accent2: #494BA6;
  --sg-radius: 14px;
  --sg-blur: 0px;
}
```

# Sales Intelligence Dashboard

CRM dashboards, sales management, opportunity tracking, performance management, quota pla…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #E5E7EB |
| surface | #d9dbdf |
| text | #18181b |
| muted | #747579 |
| accent | #FFD700 |
| accent2 | #C0C0C0 |

## 关键参数

- 质感类：dash
- 字体：sans
- 圆角：12px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Sales Intelligence Dashboard — dash */
.aek-stage {
  --p-bg: #E5E7EB;
  --p-surface: #d9dbdf;
  --p-text: #18181b;
  --p-muted: #747579;
  --p-accent: #FFD700;
  --p-accent2: #C0C0C0;
  --sg-radius: 12px;
  --sg-blur: 0px;
}
```

# Bitcoin DeFi (Mobile)

DeFi dashboards, wallets, NFT marketplaces, Web3 social, metaverse utilities, high-tech f…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #FFD600 |
| surface | #f0c900 |
| text | #030304 |
| muted | #746202 |
| accent | #EA580C |
| accent2 | #F7931A |

## 关键参数

- 质感类：glass
- 字体：mono
- 圆角：999px
- 毛玻璃：16px
- 深色底：否

## 应用 CSS

```css
/* Bitcoin DeFi (Mobile) — glass */
.aek-stage {
  --p-bg: #FFD600;
  --p-surface: #f0c900;
  --p-text: #030304;
  --p-muted: #746202;
  --p-accent: #EA580C;
  --p-accent2: #F7931A;
  --sg-radius: 999px;
  --sg-blur: 16px;
}
```

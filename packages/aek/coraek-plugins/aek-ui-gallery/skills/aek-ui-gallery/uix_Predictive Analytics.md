# Predictive Analytics

Forecasting dashboards, anomaly detection systems, trend prediction dashboards, AI-powere…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #F59E0B |
| surface | #f5a722 |
| text | #f4f4f5 |
| muted | #f4cd8c |
| accent | #8B5CF6 |
| accent2 | #8B5CF6 |

## 关键参数

- 质感类：neubrutal
- 字体：hand
- 圆角：999px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Predictive Analytics — neubrutal */
.aek-stage {
  --p-bg: #F59E0B;
  --p-surface: #f5a722;
  --p-text: #f4f4f5;
  --p-muted: #f4cd8c;
  --p-accent: #8B5CF6;
  --p-accent2: #8B5CF6;
  --sg-radius: 999px;
  --sg-blur: 0px;
}
```

# Social Proof-Focused

B2B SaaS, professional services, premium products, e-commerce conversion pages, establish…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #F9FAFB |
| surface | #ececee |
| text | #18181b |
| muted | #7d7e80 |
| accent | #33FF00 |
| accent2 | #FFB000 |

## 关键参数

- 质感类：terminal
- 字体：hand
- 圆角：12px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Social Proof-Focused — terminal */
.aek-stage {
  --p-bg: #F9FAFB;
  --p-surface: #ececee;
  --p-text: #18181b;
  --p-muted: #7d7e80;
  --p-accent: #33FF00;
  --p-accent2: #FFB000;
  --sg-radius: 12px;
  --sg-blur: 0px;
}
```

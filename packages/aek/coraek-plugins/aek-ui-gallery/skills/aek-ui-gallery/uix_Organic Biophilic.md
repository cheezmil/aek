# Organic Biophilic

Wellness apps, sustainability brands, eco products, health apps, meditation, organic food…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #F5F5DC |
| surface | #efead0 |
| text | #8B4513 |
| muted | #bb946d |
| accent | #228B22 |
| accent2 | #87CEEB |

## 关键参数

- 质感类：organic
- 字体：sans
- 圆角：20px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Organic Biophilic — organic */
.aek-stage {
  --p-bg: #F5F5DC;
  --p-surface: #efead0;
  --p-text: #8B4513;
  --p-muted: #bb946d;
  --p-accent: #228B22;
  --p-accent2: #87CEEB;
  --sg-radius: 20px;
  --sg-blur: 0px;
}
```

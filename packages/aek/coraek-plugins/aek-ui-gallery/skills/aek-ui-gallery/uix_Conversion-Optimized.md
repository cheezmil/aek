# Conversion-Optimized

E-commerce product pages, free trial signups, lead generation, SaaS pricing pages, limite…

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #22C55E |
| surface | #37ca6d |
| text | #f4f4f5 |
| muted | #96dfb1 |
| accent | #000000 |
| accent2 | #000000 |

## 关键参数

- 质感类：minimal
- 字体：sans
- 圆角：0px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Conversion-Optimized — minimal */
.aek-stage {
  --p-bg: #22C55E;
  --p-surface: #37ca6d;
  --p-text: #f4f4f5;
  --p-muted: #96dfb1;
  --p-accent: #000000;
  --p-accent2: #000000;
  --sg-radius: 0px;
  --sg-blur: 0px;
}
```

# Eco/Sustainable

Eco brands organic sustainable business

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #8FBC8F |
| surface | #99c299 |
| text | #f4f4f5 |
| muted | #c7dbc7 |
| accent | #2E8B57 |
| accent2 | #2E8B57 |

## 关键参数

- 质感类：terminal
- 字体：sans
- 圆角：12px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Eco/Sustainable — terminal */
.aek-stage {
  --p-bg: #8FBC8F;
  --p-surface: #99c299;
  --p-text: #f4f4f5;
  --p-muted: #c7dbc7;
  --p-accent: #2E8B57;
  --p-accent2: #2E8B57;
  --sg-radius: 12px;
  --sg-blur: 0px;
}
```

# Healthcare/Medical

Hospitals clinics health wellness

> 来源：UI/UX Pro Max

## 使用方法

这是一套 AEK 风格画廊 UI 皮肤。应用方式：把下面「应用 CSS」整段复制到你的工程（或 AEK 壳的样式注入处），它会以 `.aek-stage` 作用域设置 6 个 `--p-*` 调色变量 + 圆角 / 毛玻璃，UI 即呈现该质感。

## 配色（6 槽）

| 角色 | 色值 |
| ---- | ---- |
| bg | #FFFFFF |
| surface | #f0f7fb |
| text | #0077B6 |
| muted | #73b4d7 |
| accent | #00A896 |
| accent2 | #00A896 |

## 关键参数

- 质感类：terminal
- 字体：sans
- 圆角：12px
- 毛玻璃：0px
- 深色底：否

## 应用 CSS

```css
/* Healthcare/Medical — terminal */
.aek-stage {
  --p-bg: #FFFFFF;
  --p-surface: #f0f7fb;
  --p-text: #0077B6;
  --p-muted: #73b4d7;
  --p-accent: #00A896;
  --p-accent2: #00A896;
  --sg-radius: 12px;
  --sg-blur: 0px;
}
```
